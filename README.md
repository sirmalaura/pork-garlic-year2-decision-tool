# Year 2 Winter Decision Tool

Interactive website for comparing two Year 2 winter strategies for Pork & Garlic Ice Cream Co.

## Included

- Confirmed Year 1 figures from the accounting workbook
- Editable Option A and Option B assumptions
- Actual sales-allocation validation
- Profit and loss and cash-flow projections
- Negative cash before the market warning
- Side-by-side strategy comparison
- Decision and key-assumption note fields

## Vercel

Upload `index.html` to a Vercel project, or connect the GitHub repository. The logo can be uploaded as `logo.svg` and referenced by the website if desired.
